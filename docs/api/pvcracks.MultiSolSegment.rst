MultiSolSegment API
===================

.. automodule:: pvcracks.MultiSolSegment
   :members:
   :undoc-members:
   :show-inheritance:

MultiSolSegment's reusable preprocessing, segmentation, pretrained-model
loading, and visualization functions are maintained in
:doc:`the utility API <pvcracks.utils>`. That reference documents every
public runtime callable without duplicating entries in the site-wide object
index. Optional retraining and hyperparameter-optimization helpers are
distributed separately as ``pvcracks-training``.
