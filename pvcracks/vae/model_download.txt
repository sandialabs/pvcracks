The current FinalVAE3CH autoencoder state dictionary ships with pvcracks.
It is paired with the bundled XGBoost JSON models and feature metadata.

Load without downloading weights or depending on the working directory:

    from pvcracks.vae import load_unet_ae_crack_plus
    model, checkpoint = load_unet_ae_crack_plus(device="cpu")

See README.md and model_manifest.json in this package for the model contract,
checkpoint selection, artifact hashes, and pointers to current examples.
Historical VAE weights remain archived at:
https://datahub.duramat.org/dataset/pvcracks-trained-vae-model
Those earlier weights and their latent vectors are incompatible with the
current XGBoost predictors.
